# Ввод данных: датчики телефона, погода из интернета, хронограф

Статус: **утверждён 2026-10-06 в объёме фазы 1 (датчики)**, в работе. Создан: 2026-10-06.
Дорожная карта: (1) переезд на Kotlin ✅ → (2) функции конкурентов:
баллистика ✅ (план `ballistics-features.md`) → **ввод данных** → данные
(библиотеки) → (3) новый интерфейс. Источник — память
`feature-backlog-competitors`, раздел «Ввод».

Цель: условия выстрела заполняются за секунды, без ручного ввода, там, где
телефон или открытые данные это позволяют; всё заполненное остаётся
редактируемым и видно, откуда взялось.

## Что выяснено (2026-10-06)

- Приложение сейчас без единого разрешения («работает офлайн на своих
  данных», `AndroidManifest.xml`).
- **Bluetooth — не делаем** (решение пользователя: приборов нет). Протоколы и
  так закрыты: Kestrel LiNK — только для партнёров, дальномеры (Sig BDX и др.)
  — экосистема производителя.
- **Garmin Xero C1** пишет сессии в файлы FIT (открытый формат Garmin FIT SDK);
  ShotView экспортирует CSV. **LabRadar** экспортирует CSV. Импорт файлов —
  реален и проверяем без прибора (тестовые файлы по спецификации).
- **Погода**: Open-Meteo — бесплатно только некоммерчески (данные CC BY 4.0);
  MET Norway (api.met.no) — бесплатно, CC BY 4.0, нужен только User-Agent с
  контактом, коммерческое использование не запрещено. Обе без ключа.
- Платформенный слой (`Platform`) умеет только текстовые файлы; FIT —
  двоичный: нужен `openBytes`.
- Целевой телефон — Samsung S26 Ultra: барометр, GPS, магнитометр,
  акселерометр есть.

### 1. Датчики — M
- `Sensors` (expect/actual): на Android — `SensorManager` и `LocationManager`
  (без Google Play Services: работает на любом телефоне), на компьютере — нет
  (кнопки скрыты).
- Условия: «Давление с барометра» (давление на месте — ровно то, что нужно
  ядру); «Моё место» — GPS: высота, широта (Кориолис); «Азимут по компасу» —
  вектор поворота, магнитное склонение по `GeomagneticField` → истинный
  север; «Угол и завал» — телефон вдоль ствола / планки, по гравитации
  (усреднение 1 с, показ устойчивости).
- Разрешение на геолокацию спрашивается только по нажатию «Моё место».
- Проверка: Kotlin-тесты на чистые функции (склонение, усреднение, углы из
  вектора гравитации, перевод в поля условий); на эмуляторе — виртуальные
  датчики (давление, GPS, ориентация) через `adb emu`; на S26 Ultra —
  пользователь.

### 2. Погода — M
- По нажатию «Погода сейчас»: место из GPS (или введённые координаты на
  компьютере) → температура, давление (на месте: из давления на уровне моря и
  высоты точки, нашей функцией), влажность, ветер (скорость и откуда; при
  известном азимуте стрельбы — пересчёт в направление относительно линии
  огня, иначе только скорость).
- Показ источника, времени прогноза и расстояния до точки модели; отметка
  времени погоды (предупреждение «устарела» уже есть).
- Провайдер — В1. Без ключей, без фоновых запросов, только по нажатию.
- Проверка: разбор ответа провайдера на сохранённых образцах (тесты без
  сети); пересчёт давления и направления ветра — юнит-тесты; один ручной
  запрос на эмуляторе.

### 3. Хронограф — M
- Импорт файла: Garmin Xero FIT (свой разбор FIT по спецификации: только
  записи выстрелов), CSV из ShotView и LabRadar, текст «по скорости в строке».
- Итог: число выстрелов, средняя, SD, ES, мин/макс; кнопки «Скорость патрона =
  средняя» (с температурой пороха из условий, как опорной) и «СКО скорости → в
  вероятность попадания».
- Проверка: образцы файлов (FIT собирается в тесте по спецификации; CSV — по
  описаниям форматов) → те же выстрелы; статистика против ручного расчёта;
  UI-тест импорта на десктопе.

## Вопросы (рекомендация первой)

- **В1. Провайдер погоды.**
  (а) **Рекомендую MET Norway**: бесплатно без ограничения на коммерческое
  использование, CC BY 4.0, без ключа (нужен User-Agent с контактом — укажу
  адрес репозитория, не ваш e-mail).
  (б) Open-Meteo: удобнее (сразу давление на месте), но бесплатно только
  некоммерчески.
  (в) Оба, на выбор в настройках.
- **В2. Разрешения.** Интернет (для погоды) и геолокация (для GPS) появятся в
  приложении впервые.
  (а) **Рекомендую**: добавить оба, использовать только по нажатию кнопки,
  без фона; в «О программе» — что и куда отправляется (координаты — провайдеру
  погоды, с точностью до ~1 км).
  (б) Только датчики без интернета (погоду не делать).
- **В3. Угол места.**
  (а) **Рекомендую** инклинометр: телефон вдоль ствола или планки.
  (б) Ещё и через камеру с перекрестьем (наводишь на цель) — больше работы;
  предлагаю отложить на этап интерфейса.

## Допущения (поправьте сейчас, иначе так и делаю)

1. Компас даёт истинный азимут (с поправкой на склонение); точность показываю
   («калибруйте восьмёркой», если датчик сообщает низкую точность).
2. На компьютере датчиков нет: погода — по введённым координатам, хронограф —
   так же, как на телефоне.
3. Всё, что заполнено датчиками или погодой, — обычные значения условий:
   правятся руками, сохраняются как сейчас.
4. Координаты для погоды округляются до 0.01° (~1 км) перед отправкой.
5. Версия: 0.3.0 по итогам этапа «баллистика» выпускается отдельно, до начала
   этого этапа.

**Не делаем:** Bluetooth (Kestrel, дальномеры, хронографы по воздуху),
фоновые обновления погоды, камеру-инклинометр (этап интерфейса).
