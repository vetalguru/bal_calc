# Мастер создания оружия

Статус: **выполнен 2026-11-23** (утверждён 2026-11-22, ответы на вопросы — ниже);
влит в PR #119. Итог — в конце файла.
Создан: 2026-11-22.

Цель: новое оружие заводится по шагам — оружие, ствол, прицел, установка,
пристрелка, итог, — с подсказками на каждом шаге; описание оружия полнее,
чем сейчас, и то, что влияет на стрельбу (планка, ход барабана), участвует в
расчёте.

## Что есть сейчас

Одна форма `RifleEditor` из трёх секций (оружие, прицел, пристрелка):
название, калибр, высота прицела, твист и его направление, длина ствола;
единицы и цена клика (одна на обе оси), фокальная плоскость, кратность,
опорная кратность SFP, сетка; условия пристрелки. Каталоги: 126 винтовок,
50 прицелов. В базе у прицела уже есть раздельная цена клика по вертикали и
горизонтали, в форме — одна.

## Новые поля

Схема v6 (`ALTER TABLE ... ADD COLUMN`, старые базы обновляются без потерь,
значения по умолчанию — «не указано»).

Оружие (`rifle`):
- `maker`, `model` — производитель и модель (название остаётся своим);
- `rifling_grooves` — число нарезов (0 — не указано);
- `rifling_type` — `''` | `conventional` | `polygonal` | `5r` | `other`;
- `muzzle_device` — `''` | `none` | `brake` | `compensator` | `flash_hider` | `suppressor`;
- `rail_slope_rad`, `rail_slope_units` (`moa` | `mrad`) — наклон планки/основания;
- `ring_height_m` — высота колец (справочно).

Прицел (`scope`):
- `maker`, `model`;
- `tube_diameter_m`, `objective_m` — диаметр трубы и объектива;
- `elevation_travel_rad`, `windage_travel_rad` — полный ход барабанов
  (0 — не указан).

Цена клика по горизонтали — уже есть (`click_horizontal_rad`); в форме
появляется поле «по горизонтали» (по умолчанию — как по вертикали).

## Расчёт

- **Хватит ли барабана.** Вверх от нуля доступно примерно
  `ход / 2 + наклон планки` (прицел сведён около механической середины).
  Если поправка по вертикали больше — предупреждение на экране решения
  «Барабана не хватает на N MRAD — остаток выносом по сетке».
- **Калькулятор высоты прицела:** `h = расстояние от верха затвора до верха
  трубы прицела − Ø трубы / 2 + Ø затвора / 2` (ось затвора ≈ ось ствола).
  Диаметр трубы подставляется из прицела.

## Обмен

Файл оружия (`balcalc-rifle`, JSON и QR) несёт новые поля; старые файлы
читаются как раньше (новые поля — по умолчанию), старые версии приложения
новые поля пропускают.

## Мастер

Шаги (вперёд/назад, «Сохранить» на последнем; черновик живёт, пока открыт
мастер):

1. **Оружие** — из каталога или вручную: название, производитель, модель,
   калибр, фото.
2. **Ствол** — длина, твист, направление, нарезы (число, тип), дульное
   устройство; устойчивость Sg с текущим патроном.
3. **Прицел** — из каталога или вручную: производитель, модель, единицы,
   клик по вертикали и горизонтали, ход барабанов, фокальная плоскость,
   кратность, опорная кратность SFP, сетка, Ø трубы и объектива.
4. **Установка** — наклон планки, высота колец, высота прицела (картинка и
   калькулятор).
5. **Пристрелка** — дистанция и условия.
6. **Итог** — сводка по шагам с переходом к нужному шагу; «Сохранить».

Секции формы правки и шаги мастера — одни и те же составные части.

## Проверка

- C++: миграция v5→v6 (старая база с оружием → v6, значения по умолчанию),
  форма сохраняется и читается с новыми полями, проверка ввода, обмен
  (новые поля туда и обратно, старый файл без них), предупреждение о ходе
  барабана.
- Kotlin: калькулятор высоты; UI-тесты мастера (весь путь, назад, каталог,
  итог), формы правки с новыми полями; скриншоты шагов.
