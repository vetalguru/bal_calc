# Android release build

Requirements: Qt 6.9.2 with the `android_arm64_v8a` kit, Android SDK
(platform 35, build-tools 35), NDK r26b (26.1.10909125), JDK 17, with
`ANDROID_SDK_ROOT`, `ANDROID_NDK_ROOT` and `JAVA_HOME` set.

## 1. Create your signing key (once)

Keep the keystore and its passwords outside the repository and back them up:
an app update must be signed with the same key.

```powershell
& "$env:JAVA_HOME\bin\keytool.exe" -genkeypair -keystore "$env:USERPROFILE\balcalc-release.keystore" -alias balcalc -keyalg RSA -keysize 4096 -validity 10000
```

`keytool` asks for the passwords and your name; nothing is stored in the project.

## 2. Build a signed APK and AAB

Signing is switched on when `QT_ANDROID_KEYSTORE_PATH` is set
(see `app/CMakeLists.txt`):

```powershell
$env:QT_ANDROID_KEYSTORE_PATH = "$env:USERPROFILE\balcalc-release.keystore"
$env:QT_ANDROID_KEYSTORE_ALIAS = "balcalc"
$env:QT_ANDROID_KEYSTORE_STORE_PASS = Read-Host "Keystore password"
$env:QT_ANDROID_KEYSTORE_KEY_PASS = $env:QT_ANDROID_KEYSTORE_STORE_PASS
cmake --preset android-arm64
cmake --build --preset android-arm64          # APK
cmake --build build/android-arm64 --target aab # Google Play bundle
```

Outputs (under `build/android-arm64/app/android-build/build/outputs/`):

- `apk/release/android-build-release-signed.apk` - install with
  `adb install` or copy to the phone;
- `bundle/release/android-build-release.aab` - upload to Google Play.

Check the signature:

```powershell
& "$env:ANDROID_SDK_ROOT\build-tools\35.0.0\apksigner.bat" verify --print-certs <apk>
```

## Debug builds

`cmake --build --preset android-arm64-debug` gives a debug-signed APK that
installs on any device or emulator for testing.

## Notes

- Version: `QT_ANDROID_VERSION_NAME` follows `project(VERSION)`;
  `QT_ANDROID_VERSION_CODE` in `app/CMakeLists.txt` must grow with every
  release uploaded to Google Play.
- The app needs no Android permissions. Its database lives in the app's
  private storage and is included in Android's automatic backup.
- Icons are generated by `app/icons/make_icons.py`.
